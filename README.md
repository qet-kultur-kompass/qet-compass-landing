# qet-compass.com → qet.de/compass

Seit Oktober 2026 liegt die Produktseite des QET Compass auf **qet.de/compass** (Repo qet-ag-website, Datei `compass/index.html`).
Diese Domain leitet nur noch dauerhaft weiter (`vercel.json`):

- `qet-compass.com/?lang=fr` → `qet.de/fr/compass` (alle 40 Sprachen), sonst → `qet.de/compass`
- `qet-compass.com/prospekt/...` → `qet.de/compass/prospekt/...`

Die Software bleibt unter **app.qet-compass.com** (eigenes Projekt, davon nicht betroffen).
Der alte Seitenstand ist in der Git-Historie erhalten.
